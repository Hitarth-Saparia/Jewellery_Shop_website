# 🗄️ Database Architecture & Setup Guide

This directory contains the complete database scripts and schema definitions for the **Vijayraj Gems & Jewellery Shop Management System**.

---

## 📁 Files in This Directory

- **`schema.sql`**: Full DDL script creating database `vijayraj_jewellery`, tables with foreign keys, indexes, and analytical views.
- **`seed.sql`**: Comprehensive DML script inserting 50 realistic products, 50 diverse customers, 55+ multi-item invoices, and metal rate histories.
- **`procedures.sql`**: Stored procedures and triggers (stock auto-deduction, loyalty point computation, customer summary calculation).
- **`backups/`**: Directory where MySQL `.sql` backups generated by the backup service or admin panel are stored.

---

## 📊 Relational Schema Overview

### Core Tables
1. **`users`**: Store employees with roles (`admin`, `manager`, `staff`), PBKDF2 hashed passwords, and active status.
2. **`products`**: Product inventory items with category (`Gold`, `Silver`, `Diamond`, `Platinum`, `Gems`), purity (`24K`, `22K`, `18K`, `925`), weight, unit price, making charges, and stock quantity.
3. **`customers`**: Registered customers with unique code (`C01`, `C02`, ...), phone, email, address, and accumulated loyalty points.
4. **`invoices`**: Sales transactions recording customer reference, billing user, payment mode (`Cash`, `Card`, `UPI`, `Net Banking`), subtotal, discount, 3% GST, and grand total.
5. **`invoice_items`**: Line items for each invoice detailing product, quantity, unit price, making charges, and item total.
6. **`metal_rates`**: Daily market price per gram for 24K Gold, 22K Gold, 18K Gold, and 999 Silver.

### Database Views
- **`v_monthly_sales`**: Monthly aggregated revenue and invoice counts.
- **`v_daily_sales`**: Daily transaction counts and totals.
- **`v_sales_by_category`**: Turnover breakdown by jewellery category.
- **`v_sales_by_payment_mode`**: Financial breakdown by payment method.
- **`v_top_products`**: Best-selling jewellery products by quantity and revenue.
- **`v_low_stock`**: Products nearing exhaustion (`stock_qty <= 2`).
- **`v_customer_purchase_history`**: Consolidated customer order ledger.

---

## 🔄 How to Initialize or Reset the Database

From the project root:
```bash
source venv/bin/activate
python Backend/scripts/init_db.py
```
Or with MySQL command-line client:
```bash
mysql -u root -p < Database/schema.sql
mysql -u root -p vijayraj_jewellery < Database/seed.sql
mysql -u root -p vijayraj_jewellery < Database/procedures.sql
```
